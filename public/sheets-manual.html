Overview概要
Purpose and workflow summary目的とワークフロー概要

The Google Sheets export is the primary tool for reviewing and adjusting the monthly schedule after a draft is generated. Managers open the shared spreadsheet, make changes to the editable columns, and HQ syncs those changes back into the system for final approval.

Google Sheetsエクスポートは、月次スケジュールの草案（ドラフト）生成後に確認・調整するための主要ツールです。マネージャーが共有スプレッドシートを開き、編集可能な列に変更を入力すると、HQがその変更をシステムへ反映して最終承認を行います。

There are two common change types: (1) Time changes — adjusting a staff member's start/end time for a specific day; and (2) Branch transfers — moving a staff member to work at a different branch for that day. Both are handled in the same Edit Inputs section of the spreadsheet.

2種類の変更が一般的です：（1）時間変更 — 特定の日のスタッフの出退勤時間を調整；（2）ブランチ移動 — スタッフをその日に別の店舗で勤務させる。どちらもスプレッドシートの同じ「Edit Inputs」セクションで対応します。

ℹ️ Rule of thumb for Manila: Most staff keep the same branch each month. Only a small number transfer branches for specific reasons. The spreadsheet is designed so time changes are quick (just pick from a dropdown), and branch transfers are easy to spot and specify. マニラの基本ルール：ほとんどのスタッフは毎月同じ店舗勤務です。特別な理由がある少数のスタッフのみが店舗移動します。スプレッドシートは時間変更がドロップダウンで素早くできるよう設計されており、ブランチ移動も簡単に指定できます。
1
Export the Schedule to Google SheetsスケジュールをGoogle Sheetsにエクスポートする
Done once per branch, from the Draft Generator page (HQ/Admin only)店舗ごとに1回実施。Draft Generatorページから（HQ/Admin のみ）
  1. Navigate to Draft Generator / Edit / Apply in the sidebar. サイドバーから Draft Generator / Edit / Apply へ移動します。
  2. Click the Schedule View tab. If no data appears, generate a draft first via the Draft Management tab. Schedule View タブをクリックします。データが表示されない場合は、Draft Management タブでドラフトを先に生成してください。
  3. Select the target branch tab (e.g. TAFT, CUB, PAR) at the top of the schedule view. 対象の店舗タブ（例：TAFT、CUB、PAR）をスケジュールビューの上部から選択します。
  4. In the Export toolbar, click ↗ Export to Sheet (green button). The system writes the branch's schedule into the shared Google Spreadsheet in DRAFT mode. Exportツールバーの ↗ Export to Sheet（緑ボタン）をクリックします。その店舗のスケジュールが共有Google SpreadsheetにDRAFTモードで書き出されます。
  5. When complete, a ✓ Sheet updated — Open link appears. Click it to open the spreadsheet directly. 完了すると ✓ Sheet updated — Open リンクが表示されます。クリックすると書き出されたタブが直接開きます。
💡 Repeat steps 3–5 for each branch (CUB, TAFT, PAR, BO, CK) to export all branches. Each branch gets its own tab named BRANCHCODE_YYYY-MM_DRAFT_MAIN and a corresponding HEADCOUNT tab. CUB・TAFT・PAR・BO・CK の各店舗について手順3〜5を繰り返すと全店舗をエクスポートできます。各店舗のタブ名は BRANCHCODE_YYYY-MM_DRAFT_MAIN、対応するHEADCOUNTタブも自動生成されます。
⚠️ Re-exporting overwrites the previous tab. If the branch tab already exists, clicking "Export to Sheet" again will delete the old tab and create a fresh one — all previous edits in the spreadsheet will be lost. Always sync edits back first before re-exporting. 再エクスポートすると前のタブが上書きされます。店舗タブが既に存在する場合、「Export to Sheet」を再度クリックすると古いタブは削除され新しいタブが作成されます — スプレッドシートへの編集内容はすべて失われます。再エクスポートの前に必ず編集内容をSyncしてください。
Opening the spreadsheet directly スプレッドシートを直接開く

Switch to the Draft Management tab and click ↗ Open Manila draft spreadsheet (purple button) to open the shared spreadsheet. This link always opens the spreadsheet — it does not trigger a new export.

Draft Management タブに切り替えて ↗ Open Manila draft spreadsheet（紫ボタン）をクリックすると共有スプレッドシートが開きます。このリンクはスプレッドシートを開くだけです — 新しいエクスポートは実行されません。

3
Making Edits in the Spreadsheetスプレッドシートで編集する
All edits go in the Edit Inputs section — never edit other columns すべての編集は Edit Inputs セクションへ — 他の列は絶対に直接編集しない
🚫 Only edit columns in the Edit Inputs area (amber background). Do not type directly into the bar columns, Next Shift, Current Shift, or Final Preview. Only the 7 Edit Input columns accept input; all others are read-only or formula-driven. Edit Inputs（アンバー色背景）の列のみ編集してください。バー列・Next Shift・Current Shift・Final Previewには直接入力しないでください。入力を受け付けるのは7つのEdit Input列のみで、それ以外は読み取り専用またはフォーミュラで自動計算されます。
🕐
A — Time Change (Revised Start / Revised End) A — 時間変更（Revised Start / Revised End）
Adjust a staff member's working hours for a specific day 特定の日のスタッフの勤務時間を調整する
Revised Start
Select the new start time from the dropdown. Options include whole hours (08, 09…) and half-hours (08:30, 09:30…). Overnight hours appear as 00(+1), 01(+1), etc. ドロップダウンから新しい開始時刻を選択します。整時（08、09…）と30分単位（08:30、09:30…）が選べます。深夜を跨ぐ時間帯は 00(+1)、01(+1) などと表示されます。
Revised End
Select the new end time from the same dropdown. Must be after Revised Start. 同じドロップダウンから新しい終了時刻を選択します。Revised Start より後の時刻を選択してください。
💡 After entering Revised Start and Revised End, the Final Preview bars (orange) on the right will automatically update to show the new schedule. The row turns yellow and Change Flag shows CHANGED. Revised Start と Revised End を入力すると、右側の Final Preview バー（オレンジ）が自動的に更新され、新しいスケジュールが表示されます。行が黄色になり、Change Flag に CHANGED と表示されます。
ℹ️ To clear a time change: delete the content of both Revised Start and Revised End cells. The row will revert to its original schedule. 時間変更を取り消す場合：Revised Start と Revised End の両セルの内容を削除してください。行は元のスケジュールに戻ります。
🔄
B — Swap with Another Staff B — 別スタッフとシフトを交換する
Exchange shifts between two staff members on a specific day 特定の日に2人のスタッフのシフトを交換する
Swap With Staff
Select the staff member to swap with from the dropdown (all active staff are listed). ドロップダウンからシフト交換する相手のスタッフを選択します（全アクティブスタッフが一覧表示されます）。
Swap Start
The new start time for this row's staff member after the swap. 交換後、この行のスタッフの新しい開始時刻を入力します。
Swap End
The new end time for this row's staff member after the swap. 交換後、この行のスタッフの新しい終了時刻を入力します。
⚠️ All three Swap fields (Swap With Staff, Swap Start, Swap End) must be filled in together. Leaving any one empty means the swap will not be recognized. Use Revised Start / Revised End for simple time changes without swapping. Swap With Staff・Swap Start・Swap End の3フィールドすべてをまとめて入力してください。1つでも空欄があるとスワップとして認識されません。スタッフを変えずに時間だけ変更する場合は Revised Start / Revised End を使用してください。
🏢
C — Branch Transfer C — ブランチ移動（Transfer Branch）
Move a staff member to work at a different branch for that day/period スタッフを特定の日/期間、別の店舗で勤務させる
Transfer Branch
Select the destination branch from the dropdown. Only other active branches in the same city are shown (the current branch is excluded). Options for Manila: CUB, TAFT, PAR, BO, CK. ドロップダウンから移動先の店舗を選択します。同じ都市のその他のアクティブ店舗のみ表示されます（現在の店舗は除外）。マニラの場合の選択肢：CUB、TAFT、PAR、BO、CK（このシートの店舗を除く）。
💡 You can combine a branch transfer with a time change by filling in both Transfer Branch and Revised Start / Revised End in the same row. Transfer Branch と Revised Start / Revised End を同じ行に入力することで、ブランチ移動と時間変更を同時に指定できます。
ℹ️ Most Manila staff do not transfer branches month-to-month. Only fill this column for the few staff who are moving locations. Leave it blank for all other rows. マニラのスタッフの多くは月ごとの店舗移動はありません。移動するスタッフの行にのみこの列を入力してください。それ以外の行は空白のままにしてください。
📝
D — Note D — メモ（Note）
Free-text comment for HQ reference HQ参照用の自由記述コメント
Note
Type any comment about the change — reason for transfer, special request, etc. Adding a note alone (without any time/swap change) will also trigger the CHANGED flag. 変更に関するコメントを自由に入力してください（移動の理由、特別なリクエストなど）。Note のみの入力（時間・スワップ変更なし）でも CHANGED フラグが立つため、HQがSync時に確認できます。
Change Flag column — how to know your edits were recorded Change Flag 列 — 編集が記録されたか確認する方法

The Change Flag column (far right, before the hidden columns) automatically shows CHANGED in any row where at least one Edit Inputs cell is non-empty. The entire row also highlights yellow. This is formula-driven — you do not type here.

Change Flag 列（右端、隠し列の前）は、Edit Inputs列のいずれかが空でない場合に自動的に CHANGED と表示されます。行全体も黄色になります。これはフォーミュラで自動計算されるため、ここには何も入力しないでください。

If a row still shows Change Flag empty after your edit, check that you used the dropdown — do not type times manually.

編集後も Change Flag が空のままの場合、時刻はドロップダウンで入力したか確認してください — 手入力はしないでください。

4
Sync Edits Back to the System編集内容をシステムへ反映する
After all edits are done in the spreadsheet, HQ reads them back into the systemスプレッドシートの編集が完了したら、HQがシステムへ読み込みます
  1. Go to Draft Generator / Edit / Apply → Draft Management tab. Draft Generator / Edit / Apply → Draft Management タブへ移動します。
  2. Scroll down to the Pending Sheet Proposals section. Pending Sheet Proposals セクションまでスクロールします。
  3. Set the Month and Branch Filter fields to match the sheet you edited. Month と Branch Filter を編集したシートに合わせて設定します。
  4. In the MAIN Tab Name dropdown, select the tab that was edited (e.g. CUB_2026-08_DRAFT_MAIN). If the dropdown is empty, click the ↻ refresh button next to A1 Range to load the tab list. MAIN Tab Name ドロップダウンで編集したタブを選択します（例：CUB_2026-08_DRAFT_MAIN）。ドロップダウンが空の場合は、A1 Range 横の ↻ ボタンをクリックしてタブ一覧を読み込んでください。
  5. Click ↓ Sync Proposals From Sheet. The system reads all rows where Change Flag = CHANGED and creates proposals for each one. ↓ Sync Proposals From Sheet をクリックします。Change Flag = CHANGED のすべての行が読み込まれ、それぞれの提案が作成されます。
  6. The proposals appear in the table below with columns: DATE, BRANCH, BEFORE, AFTER, SWAP, NOTE. Review them to confirm they match your intended edits. 下の表に提案が表示されます（DATE・BRANCH・BEFORE・AFTER・SWAP・NOTE）。意図した変更内容と一致しているか確認してください。
ℹ️ A1 Range can usually stay at the default A1:CL2000. Only change it if you need to limit which rows are scanned. The ↻ button refreshes the tab list without changing the range. A1 Range は通常デフォルト（A1:CL2000）のままで問題ありません。スキャン範囲を制限したい場合のみ変更してください。↻ ボタンはタブ一覧を更新するだけで、範囲は変更されません。
5
HQ ApprovalHQ承認
Review synced proposals and approve or reject them in bulkSync後の提案を確認し、まとめて承認または却下する
  1. Click ↻ Refresh Pending (top right of Pending Sheet Proposals) to load the latest proposals. Pending Sheet Proposals の右上の ↻ Refresh Pending をクリックして最新の提案を読み込みます。
  2. Review each row in the proposals table. Verify that BEFORE and AFTER times look correct, and that branch transfers (if any) are going to the right destination. 提案一覧の各行を確認します。BEFORE・AFTER の時刻が正しいか、ブランチ移動（あれば）が正しい移動先になっているか確認してください。
  3. Check the boxes next to the proposals you want to act on. Use the checkbox in the table header to select all. 対応したい提案のチェックボックスをオンにします。テーブルヘッダーのチェックボックスで全選択もできます。
  4. Optionally fill in a Decision Note (optional) — a short reason for your decision. 必要に応じて Decision Note（optional） に短いコメントを入力します（例：「ブランチ移動 — 管理職承認済み」）。
  5. Click ✓ Approve Selected to approve, or ✕ Reject Selected to reject. Approved proposals are applied to the draft. ✓ Approve Selected をクリックして承認、または ✕ Reject Selected で却下します。承認された提案はドラフトに反映されます。
⚠️ Approving a proposal does not automatically update the live (published) schedule. The draft must still go through the normal week-by-week publish process via the Schedule View tab. Approval here means "HQ has reviewed and confirmed this change for the draft." 提案を承認しても、スケジュールが即座に公開（ライブ）されるわけではありません。ドラフトは引き続き、Schedule Viewタブの通常の週ごとの公開プロセスを経る必要があります。ここでの承認は「HQがこの変更をドラフトとして確認・承認した」ことを意味します。

Tips & Rules 注意事項
✅ Always use the dropdowns for time fields. Typing a time manually may not be recognized by the sync system. 時刻フィールドは常にドロップダウンを使用してください。手入力はSyncシステムが認識しない場合があります。
✅ Check the Final Preview orange bars after each edit — they immediately reflect your changes. 編集後は右側のFinal Preview（オレンジバー）を確認してください。変更内容が即座に反映されます。
⚠️ Do not add or delete rows. Do not merge cells. The sync reads rows by position. 行の追加・削除はしないでください。セルの結合もしないでください。Syncは行の位置を基準に読み取ります。
⚠️ Overnight end times (e.g. 02(+1)) are next-day hours. Use them for shifts that end after midnight. 深夜を跨ぐ終了時刻（例：02(+1)）は翌日の時刻です。深夜0時以降に終了するシフトに使用してください。
ℹ️ The HEADCOUNT tab updates automatically on re-export. It shows how many staff are on per hour each day — useful for confirming coverage. HEADCOUNTタブは再エクスポート時に自動更新されます。日ごと・時間ごとのスタッフ人数が表示され、カバレッジの確認に役立ちます。
ℹ️ A FINAL export (FINAL mode) happens automatically when weeks are published via the publish process. The DRAFT export is for manager review only. FINALエクスポート（FINALモード）は、週を公開する際に自動実行されます。DRAFTエクスポートはマネージャーの確認用のみです。
