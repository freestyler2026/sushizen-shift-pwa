新しいスタッフを登録する

登録は Create Staff Record の1画面で完結します。ここで入れた入社日は 在職証明書に印字され、シフトの自動生成にも使われるので、契約書を見ながら 入力してください。所要およそ2分です。

先に手元に用意するもの 雇用契約書（氏名・入社日・役職・雇用会社）、自分のログインPIN、 そして本人の携帯。最後にその場でPINを作ってもらうのが一番早く終わります。

手順

  1. Staff ページを開く

    サイドバーの ADMIN → PEOPLE & ACCESS を開いて Staff。そこの「Add New Staff」で Go to Create Staff を押します。 直接なら /admin/staff/create。

    PEOPLE & ACCESS は既定で閉じています。開かないと Staff は出てきません。Admin Dashboard 上部の横並びリンクからも行けますが、 そちらでは同じ画面が Staff Master という名前になっています。

    Staff ページの一覧からは登録できません。マニラは役職・入社日・ 雇用会社が必須で、一覧の簡易フォームにはその欄が無いためです。入口はこの1つだけです。

  2. City と Branch を選ぶ

    マニラの選択肢は PAR CUB TAFT CK WH BO の6つです。

    MANAGER の人は自分の拠点しか選べません。他の拠点を選ぶと 「manager can create staff only in own branch」で弾かれます。 ADMIN・HQ・HR_MANAGER は全拠点を登録できます。

  3. 氏名を入力する

    契約書どおりのフルネームで。この名前が打刻・シフト・給与すべての 紐付けキーになります。ミドルネームの有無や綴りが違うと、同じ人が二重に登録された 状態になります。

  4. マニラの3項目を埋める（マニラのみ必須）

    Position Hire Date Employing Company の3つです。1つでも空だと保存できません。 ドバイでは表示されません。

    入社日は2025年8月1日より前を受け付けません。マニラ1号店の準備開始が その月だからです。それ以前の日付は打ち間違いとして扱われます。

  5. Role と Status はそのまま

    Role は STAFF、Status は ACTIVE のままで結構です。店長として登録する場合だけ Role を MANAGER にします。 細かい権限は登録後に Role Management で付けます。

  6. 自分の名前とPINを入れて作成する

    Manager Name と Manager PIN はログイン情報から自動で入っています。 空のときだけ自分で入れてください。登録する人（あなた）のもので、 新しいスタッフのものではありません。画面上部の Verified role に 自分の権限（HQ など）が出ていれば通ります。

    氏名・Manager Name・Manager PIN の3つが揃うまでボタンは押せません。 灰色のままなら、このどれかが空です。

  7. Setup Code を本人に渡す

    6桁の Setup Code が表示されます。Copy Setup Code でコピーできます。

    有効期限は72時間です。切れたら Onboarding & Setup の Reset PIN で作り直せます。

    ⚠️ 画面に出る期限はUTC表示です。 2026-09-23T10:54+00:00 と出ていたら、 マニラでは9月23日の18時54分（+8時間）、ドバイでは14時54分（+4時間）です。 そのまま読むと半日早く切れると勘違いします。

  8. 本人にPINを作ってもらう

    本人の携帯で /setup-pin を開き、 氏名 · Setup Code · 新しいPIN を入力します。 作成画面の Open Set Up PIN からそのまま開けます。

    PINは数字4〜8桁。1111 やゾロ目、 1234 のような連番は拒否されます。 PINは給与明細の前に立つ唯一の鍵なので、その場で本人に決めてもらってください。

入力項目の一覧

「必須」はサーバー側で検証されます。空のまま保存すると赤いエラーが出ます。

項目必須内容
City必須Dubai / Manila
Branch必須マニラは PAR / CUB / TAFT / CK / WH / BO。MANAGER は自拠点のみ
Staff Name必須契約書どおりのフルネーム。全システムの紐付けキー
Date of Birth任意生年月日
Marital Status任意Single / Married / Widowed / Separated

Hire Dateマニラ必須契約書の入社日。2025-08-01 より前は不可。在職証明書に印字
Employing Companyマニラ必須SUSHIZEN または 7CZ ANGEL CORP.。在職証明書に印字
Role必須STAFF / MANAGER
Status必須ACTIVE のままにする

入社日・役職・雇用会社は、後から復元できません 打刻やシフトの記録から逆算することはできず、契約書を探し直すしかなくなります。 フィリピンの在職証明書（COE）は請求から3営業日以内に出す義務があり、 この3項目が空だと発行できません。だから登録時の必須項目にしてあります。

登録したあと

PIN未設定の人を確認する

Staff → Onboarding & Setup
まだPINを作っていない人が Pending として並びます。 期限切れは各行の Reset PIN で作り直せます （Setup PIN は本人の設定画面を開くボタンで、別物です）。

ランクを設定する

/admin/staff-ranks
L0〜L10。L7以上がシフトのPIC（責任者）として数えられます。 未設定のままだと自動生成がPIC不足の警告を出します。

権限を付ける

Staff → Role Management
店舗スタッフは既定のままで足ります。発注や在庫を触る人だけ、 ここでチャンネルを追加します。

在籍状態を変える

Staff の一覧で ACTIVE / ON_LEAVE / SEPARATED を切り替えます。 休職・退職はどちらもアカウントを凍結し、違いは権限を残すか奪うかだけです。
一覧は「Login & Load」を押すまで空（0 members）です。 自分の名前を入れて読み込んでから探してください。

入社日はシフトの自動生成にも使われます

2026年9月20日から、Draft の自動生成が 入社日を読むようになりました。 この欄の意味が1つ増えています。

  • 入社日より前の日には組まれません。 以前は9月15日入社の人にも月26日分のシフトが入っていて、 1人あたり20行を手で消す必要がありました。
  • 入社日が入っていれば、初月からDraftに出ます。 以前は「先月のシフトに出ていない人」を除外していたため、 新人は入社から丸1か月以上、Draftに一切現れませんでした。 8月24日以降に手入力された190セルは、全部この新人分でした。
  • 入社日は2か所に同時に書かれます。 試用期間の管理が staff_master.hired_at、 給与の日割りが official_hire_date を読みます。 この画面から入れれば必ず一致します。
週の上限日数・連続勤務日数は、いまは画面から変えられません 一覧に max/wk:6 | max/cons:6 と表示されますが、 表示だけで編集欄がありません。全員が6日・6連勤で固定です。 特定の人だけ変える必要が出たら、そのとき編集欄を作ります。

つまずきやすいところ

  • 「Create Staff Record」が押せない 氏名・Manager Name・Manager PIN のどれかが空です。この3つが揃うまでボタンは無効のままです。
  • 保存すると赤いエラーが出る（マニラ） Position / Hire Date / Employing Company のどれかが空です。実際の文言は 「position, hire_date, company required. These are printed on the Certificate of Employment and cannot be recovered later.」で、足りない項目名がそのまま並びます。
  • 入社日が古すぎると言われる 「hire_date is earlier than 2025-08-01. Check the contract.」。 日付入力欄がそれ以前を選ばせない作りですが、貼り付けなどで入った場合はサーバーが止めます。
  • 「manager can create staff only in own branch」 MANAGER が自分以外の拠点を選んでいます。その拠点の店長か、ADMIN・HQ・HR_MANAGER に依頼してください。
  • 「invalid approver credentials」 Manager Name か PIN が違います。新しいスタッフのPINではなく、あなたのPINです。
  • 本人が Setup Code を入れても通らない 72時間を過ぎています。Onboarding & Setup から再発行してください。
  • PINが「決められない」と言われる 1111・ゾロ目・1234 のような連番は 「Pick a PIN that is not 1111, four of the same digit, or digits in a row like 1234.」で拒否されます。 4桁未満は「PIN must be 4 to 8 digits」、入力欄2つが違うと「PIN confirmation does not match」、 Setup Code が違うと「Invalid setup code」です。
  • Staff の一覧に誰も出てこない この画面は開いた時点では 0 members です。上の 「Login & Load」を押すまで読み込まれません。登録した人が消えたわけではありません。
  • 期限が切れているように見える Onboarding の Expires はUTC表示です。マニラは+8時間、ドバイは+4時間して読んでください。
  • 同じ人が2人いる 氏名の綴りが違うと別人として登録されます。打刻と給与が分かれるので、気づいた時点で統合が必要です。登録時に契約書を見るのが唯一の予防策です。
画面: /admin/staff/create ・ /admin/staff ・ /admin/staff/onboarding ・ /setup-pin。 登録は staff_created として監査ログに残り、 作成画面の「View Audit Logs」から本人分だけを開けます。 2026年9月20日に本番で1件登録して全手順を通し、確認後そのレコードは削除しました。 画面の文言・エラーメッセージ・72時間の期限・PINの規則は、すべてそのときの実測です。
