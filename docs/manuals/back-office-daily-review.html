Reading what the stores sent店舗から届いたものを読む

The stores file eight things a day. Until somebody here has read one, nothing is known about that store’s day — a report can arrive on time and still be wrong.

店舗は1日に8件を提出します。それをここで誰かが読むまで、その店のその日について何も分かりません。 時間どおりに届いていても、中身が正しいとは限らないためです。

Where this is done作業する場所
Menu›Store Operations›BO Dashboard›Required Reports

There is no menu entry of its own — it is a tab across the top of the BO Dashboard, next to Owners and Par Levels.

独立したメニュー項目はありません。BO Dashboard の上部タブとして、 Owners や Par Levels と並んでいます。

Four stages, not two段階は2つではなく4つ

1 · Submitted1・提出 The store filed it. This part is already done for you. 店舗が出した状態。ここは自動で埋まります。
2 · Reviewed2・点検 You read it. This is your part. 読んで確認する。ここが担当分です。
3 · Issue found3・問題あり Only if something is wrong. Write what. おかしい場合のみ。内容を書きます。
4 · Action taken4・対処 What was done about it, and by whom. 何をしたか、誰がしたか。

Marking something reviewed with no issue is a real answer and takes one tap. Stage 3 and 4 are only for the ones that are actually wrong.

問題が無ければ「点検済み・問題なし」で1タップです。 3と4は、実際におかしかったものだけに使います。

“No Disposal” is a submission, not a blank. From 21 September the closing person can file a day on which the disposal logbook was empty. Those rows read No Disposal instead of an item count, and they satisfy this item — because the store did report. Read them the way you read any other: the thing worth noticing is a branch that declares it most nights. A row marked No Disposal — superseded is a day someone declared zero and disposal was entered afterwards; the declaration is kept on purpose, so that it can be counted.

「No Disposal」は空欄ではなく提出です。 2026年9月21日から、閉店担当がログブックに1件も無かった日を提出できます。 その行は明細件数の代わりに No Disposal と表示され、 この項目は提出済みとして扱われます — 店舗は報告したからです。 点検の仕方は他と同じで、見るべきはほぼ毎晩これを出している拠点。 No Disposal — superseded の行は、ゼロと宣言した日に後から廃棄が 入力された日です。数えられるように意図して残しています。

Opening Report and Opening Travel Path are one submission. Both read the same record, so when the store files the opening travel path, both lines fill. Reviewing it once answers both.

Opening Report と Opening Travel Path は同じ提出物です。 どちらも同じ記録を読んでいるため、店舗が Opening Travel Path を出すと両方の行が埋まります。 点検も1回で両方に効きます。
