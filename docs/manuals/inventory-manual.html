CK Daily Inventory Session
Store → CK Daily Inventory  /  店舗 → CK日次在庫
CK staff record inventory sessions (Pre/Post-Delivery or Daily). Multiple staff share one session per day.
🔑 Key Concept: Shared Session Model

One session per date+type. New Session auto-joins an existing one. FILLED BY column shows attribution per item.

You (green) = your entry First name (amber) = another staff's entry — = not filled yet
How to Open or Join a Session
  1. 1
    Click "New Session"

    Select date and type. Banner shows auto-join behavior.

  2. 2
    Click "Open / Create Session"

    Joins existing Draft, or creates new session.

  3. 3
    Enter quantities

    Grouped by category. Previous qty shown for delta. FILLED BY updates as staff save.

  4. 4
    Click "Save Draft" regularly

    Saves only your changes. Auto-refresh every 30s shows others' entries.

  5. 5
    Click "Finalize & Lock" when complete

    Locks session. Anyone can finalize. No edits after.

Editing Another Staff's Entry

Amber Qty field = another staff's entry. Confirmation dialog appears on first click. Approved once per session load.

Session List (Left Panel)

Date, type, item count, status, contributor names shown per card.

KPI Bar
Total Items Filled In (green when all done) Prev Session (for delta)
Roles & Permissions
All Staff: create, join, enter, save, finalize HQ/Mgmt: also Manage Items
Connected Pages
CK Inventory (Admin — stock baseline) Items Master (CK processed items list)

Full Inventory Count
Admin → Inventory → Full Count
Formal monthly count (15th and month-end). Items by supplier. Draft → Submit → Close & Post.
Starting a New Count
  1. 1
    Configure header

    City, Branch, Date, Cycle (15TH/MONTH_END), PIC, Approver.

  2. 2
    Load template or add manually

    Select a template to auto-populate, or add items one by one.

  3. 3
    Enter quantities

    Items grouped by supplier. Arrow keys step value; Enter moves down.

  4. 4
    Toggle Detail columns

    "Show Details" reveals Theoretical, Price, Variance per line.

  5. 5
    Save Draft

    Progress bar: amber → emerald when done.

Transfer Orders
Admin → Inventory → Transfer Orders
Move stock between branches. PENDING → RECEIVED → COMPLETED. Posts TRANSFER_OUT/IN to Ledger.
Creating a Transfer Order
  1. 1
    Fill the header

    City, From Branch, To Branch, Requested By, Date, Notes.

  2. 2
    Add ingredients

    Search from Items Master. Select to add lines.

  3. 3
    Set quantities

    Enter qty and unit per line.

  4. 4
    Create Transfer Order

    Creates with PENDING status. TRANSFER_OUT posted to From Branch immediately.

Transfer Lifecycle
PENDING→ RECEIVED→ COMPLETED
ActionWhoWhat happens
CreateFrom branchPENDING; TRANSFER_OUT to From Ledger
Mark ReceivedTo branchRECEIVED; TRANSFER_IN to To Ledger
CompleteEither branchCOMPLETED (locked)
CancelWhile PENDING onlyReverses TRANSFER_OUT
Export to CSV

Export filtered transfer list as CSV from the list view.

Connected Pages
Items Master (ingredient source)Ledger (TRANSFER_OUT / TRANSFER_IN events)
⚠️Cancel only works while PENDING. After RECEIVED, create a reverse transfer to undo.

Qty Adjustments
Admin → Inventory → Qty Adjustments
Increase or decrease stock quantities with a reason. Posts ADJ_CLOSE to Ledger on close.
Creating an Adjustment
  1. 1
    Fill header

    City, Branch, Date, Reason, Notes.

  2. 2
    Set direction

    Toggle INCREASE or DECREASE for the whole adjustment.

  3. 3
    Add items

    Search from Items Master. Enter qty and unit per line.

  4. 4

  5. 5
    Close & Post ⚠

Reason Codes

Inventory Ledger
Admin → Inventory → Ledger
Read-only audit log. Every Close & Post writes here. The source of truth for current stock.
Filters
CityBranchDate rangeEvent typeItem name

Default last 30 days. All filters combine with AND.

Current Balances Table

Latest balance for every item at the selected branch. Columns: Item, Unit, Current Qty, Current Cost.

Ledger Movements — Event Types
EventSource actionEffect
COUNT_CLOSEFull Count → Close & PostSets balance to counted qty
SPOT_CLOSESpot Check → Close & PostSets selected items to counted qty
ADJ_CLOSEQty/Cost Adjustment → Close+/− balance or updates cost
PRODUCTION_CLOSECK Production → CloseDeducts raw materials used
TRANSFER_OUTTransfer Order createdReduces From Branch balance
TRANSFER_INTransfer Order receivedIncreases To Branch balance
PURCHASE_RECEIVEPurchase Order receivedIncreases balance (from Procurement)
OPENINGInitial stock setupSets opening balance
MANUALAdmin direct entryFree-form correction (admin only)
Connection to All Other Pages

The Ledger is the central hub — every Close & Post writes here, irreversibly.

Full Count → COUNT_CLOSE Spot Check → SPOT_CLOSE Qty Adj → ADJ_CLOSE Cost Adj → ADJ_CLOSE Transfer → TRANSFER_OUT/IN CK Production → PRODUCTION_CLOSE Procurement → PURCHASE_RECEIVE
💡Ledger is read-only. To undo a wrong entry, create a new adjustment that offsets it.
