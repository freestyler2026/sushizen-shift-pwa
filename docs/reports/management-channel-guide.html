報告してもらった4点

すべて直しました。調べたところ、報告より大きな不具合が3つ見つかりました。

指摘調べて分かったこと対応
時刻でしか
判別できない		 その時刻が8時間ずれていました。マニラの23:21の写真が15:21と表示されていました（ドバイは4時間）。判別できなくて当然です。 現地時刻に統一。一覧に Time 列を追加。さらにアラートに写真を直接表示したので、探す作業自体が不要になりました。
選択肢だけで
閉じられる		 「フィードバックした」だけでは、どこで何を言ったかが残りません。 Feedback を選ぶと Discord / Kitchen のどちらか必須。Training を選ぶと内容1行が必須。本部から確認・修正できます。
CK のアラートを
消してほしい		 CK は Cubao として提出しているため、追う対象ではありませんでした。 対象から除外。既存分も削除。今後は出ません。
ほぼ提出済みなのに
アラートが出る		 アラート側が間違っていました。①その日が終わる前（現地0:15）に「今日の分がない」と判定 ②重複チェックの誤りで1日54件の重複。 期限を過ぎてから判定するよう修正。重複を整理し 445件 → 143件。アラート本文に日付を追加。

あわせて、送信すらできないアラートが9件ありました（サーモン歩留まり・廃棄・コスト系）。 送信文が用意されておらず、作られるのに誰にも処理できない状態でした。これも追加済みです。

この仕組みの考え方

判断はシステムが持ちます。人は決められたことを実行します。 「自分で気づいて、自分で調べて、自分で判断する」形にすると、忙しい日に必ず抜けます。

役割やること判断
OS異常を検知して、色を付けて、担当者に振り分ける不要
バックオフィス自分のページの色を見る → 定型文を送る → 結果を記録する不要
店舗マネージャー届いた指示を実行して、選択肢で答える不要
エリアマネージャー週次の点数だけを見る点数で判断

マネージャーが自分でダッシュボードを見に行く運用にはしていません。 指示は届きます。届いたものに答えてください。

手順

  1. 色を見ます。赤はいますぐ。黄はその日のうちに。
  2. 上のマニュアルを読みます。その色で何をすべきかが書いてあります。
  3. [ Send ] を押します。定型文が入っているので、そのまま送れます。
  4. 返答が来たら、対応内容を記録します。下の Handling 欄です。

  [ Feedback given ]  [ Training done ]  [ Cannot — … ]

Feedback を選んだ場合
  Where did you give the feedback?
  [ Discord ]   [ Kitchen ]        ← どちらか必須

Training を選んだ場合
  What did the training cover? (one line)   ← 必須

「Cannot」は正直に選んでください

人手が足りない、システムが動かない——実行できない事情があるときは 「Cannot」を選んでください。評価を下げることはありません。 これは店舗が助けを求める合図として扱います。同じ理由が繰り返されたら、 その資源を持っている人に回ります。無理に「Done」にすると、その問題は誰にも見えなくなります。

Waiting for Someone — 本来は空のはずの画面

ここに出るのは 「誰も担当していない」か「期限を過ぎた」ものだけです。 担当が毎日きちんと見ていれば、ここには何も落ちてきません。

ここに溜まっているということは、手前のどこかが回っていないという意味です。 数字が減らないときは、担当設定か期限の設定が実態に合っていません。遠慮なく言ってください。

この画面でも対応は完結します。移動しません。ただし 「キャンセル 7日以上未完了」だけは、その1件を開きます——返金の判断は記録を見ないとできないので、 中身を見ずに閉じる操作は作りませんでした。

いまやってほしいこと

優先内容理由
1 残業申請 30件のレビュー 承認も却下もされていません。給与計算で必ず問題になります。
2 [ Send ] を押す運用を始める 556件が一度も送信されていません。押さないかぎり何も動きません。
3 PM Backup の未提出を店舗に確認 TAFT 8/26・8/27、Dubai BB 8/26・8/27。整理後に残ったものは本物です。
4 Required Reports の黄色を緑にする 提出された報告を誰も読んでいない状態をなくすためです。
5 キャンセル 100件を進める 7日以上放置されています。減らないようなら期限を見直します。

困ったときは

遠慮なく言ってください

「担当が付いていないアラートがある」 — 設定漏れです。すぐ直します。
「この期限は現場に合っていない」 — 私が仮に決めた値なので、希望を教えてください。
「この種類はそもそも出さなくていい」 — 外します。
「アラートの内容が間違っている」 — 今回の4点がまさにそれでした。

今回の指摘は、実際に使ってみないと分からないものばかりでした。 特に時刻のずれと重複は、データを見ているだけでは気づけません。細かいことでも構いません。
