Dubai の入金はなぜ合わなかったか

「Keeta は Sushi ZEN の入金しか入っていない」「Careem / Noon は金額が合わない」という報告について調査しました。 原因は3件あり、すべて修正済みです。

報告された症状

経理からの報告 — 2026-08-27
  • Keeta は OS 上に Sushi ZEN の入金しか入っていない
  • Careem / Noon は金額が合わない（入金のほうが少し多い）

調査の結果、これは1つの不具合ではなく、別々の原因が3件重なったものでした。 Noon については取り込み自体に問題はなく、下記3件のいずれにも該当しません。

判明した原因

Careem — 同じ売上が2回計上されていた

AED 81,073.63 修正済み
現象
Careem の一覧に、確定した週次サイクルの行と、日々の残高速報の行（careem_balance_*）が両方表示されていました。同じ売上が2つの行として合計に入るため、OS の金額が実際の入金より大きくなります。
範囲
残高速報30行のうち、8/22・8/23 の20行がサイクル行と重複。8/25 の10行（AED 9,851.80）はまだ対応するサイクルが確定していないため、重複ではありません。
修正
一覧の既定表示から残高速報の行を除外しました。行自体は削除していませんので、サイクル確定前の速報値として必要になれば参照できます。

Keeta — Ramen ZEN が丸ごと入っていなかった

AED 279,650.83 修正済み
現象
Keeta はブランドごとに別のログインアカウントになっています。自動取得は Sushi ZEN のアカウントしか見ていなかったため、Ramen ZEN の入金が OS に1件も入っていませんでした。銀行には入金が来ているので、照合すれば必ず差が出ます。
対象店舗
Arjan / Al Barsha 3 / Business Bay / Jumeirah Lake Towers / Al Mina の5店舗。
修正
自動取得を2アカウント対応にし、2025年10月〜2026年8月の142件を取り込みました。今後は毎週火曜の自動実行に Ramen ZEN も含まれます。

ブランドでの絞り込みが機能していなかった

1,285 / 1,758 件 修正済み
現象
Dubai の入金 1,758件のうち 1,285件（73%）はブランドが未設定でした。設定済みの分も sushi_zen / Sushi ZEN / all_veggie_sushi / all_veggie と表記が4通りに割れていました。
影響
画面側は表示名で照合していたため、ブランドを選んでもほとんど何も表示されない状態でした。ブランド別に金額を確認できなかったことが、差異の切り分けを難しくしていました。
修正
店舗コードからブランドを補完し、表記を sushi_zen / ramen_zen / all_veggie に統一。Dubai 1,900件すべてにブランドが入り、未設定は0件になりました。変更前の状態はバックアップ済みです。

修正作業中に判明した2件

Keeta の Ramen ZEN を取り込む過程で、取得の仕組み自体に不具合が2件見つかりました。どちらも放置すると同じ欠落が再発します。

ログイン情報が保存できず、取得を開始できなかった

修正済み
現象
Keeta の自動取得はログインセッションを保管して使いますが、保存形式が未圧縮だったため 74,924文字となり、保管先の上限（48KB）を超えて登録できませんでした。
修正
書き出し時に圧縮するようにし、18,748文字に収まりました。読み込み側は元々圧縮に対応していたため、書き出し側だけが抜けていた形です。次回のセッション更新時に同じ問題は起きません。

2026年6月より前の Ramen ZEN が取り込まれなかった

修正済み
現象
Keeta の古いレポートは店舗名の列が空欄です。店舗名から店舗を特定する作りだったため、1回目の実行では2026年6月以降しか取り込めず、82件がスキップされていました。
修正
店舗IDは変わらないため、IDで直接対応させるようにしました。2回目の実行で2025年10月まで遡って取得完了、スキップは0件です。

Noon について

取り込みは正常でした。Ramen ZEN・All Veggie とも欠落はなく、Keeta のような問題は起きていません。 今回の3件はいずれも Noon の差異の説明にはなりません。

ただし Careem の二重計上を除外した数字は変わっていますので、まず修正後の金額で再度ご確認ください。 それでも差が残る場合は、差が出ている期間と金額をお知らせいただければ特定できます。

ご確認いただきたいこと

照合済みの期間に、確認漏れが隠れている可能性があります

銀行照合の画面は、入金額の入力欄に OS の金額をあらかじめ入れた状態で表示されます。 そのまま保存すると必ず一致するため、初期値のまま確定された期間があると、差額がそこで見逃されます。

特に Keeta は、Ramen ZEN が欠落したまま照合済みになっている期間があるはずです。 実際の入金額と照らして再確認をお願いします。
