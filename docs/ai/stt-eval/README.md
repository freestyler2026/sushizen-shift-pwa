# 文字起こしエンジンの比較 — 2026-09-06

Phase 2（音声面接の文字起こし）でどのエンジンを使うかを決めるための実測。
**数字はすべて実行結果**で、推定は含まない。

## 何を測ったか

FLEURS（Google の多言語音声、`google/fleurs`）の **fil_ph（フィリピン語）20文**と、
**同じ文IDの en_us（英語）20文**。349文が両言語に存在する対訳なので、
同じ内容の英語版・タガログ版が揃う。

音声は**うちの実際の配信形式**まで落として測った。これをやらないと
「スタジオ品質でどれが強いか」しか分からない。

| 条件 | 中身 |
|---|---|
| `clean` | 元の 16 kHz WAV（上限を知るための対照） |
| `opus` | **Opus 24 kbps モノラル WebM**＝MediaRecorder が実際に書き出す形式 |
| `noisy` | opus にピンクノイズを重ねたもの（**レベルは私が決めた値。厨房の実測ではない**） |
| `mix` | 英語音声とタガログ音声を1本に連結（タグリッシュの**粗い代用**） |

## 結果

### 単一言語（うちの opus 形式）

| モデル | タガログ | 英語 |
|---|---:|---:|
| whisper-1 | 12.7% | 5.5% |
| gpt-4o-transcribe | **6.6%** | **4.0%** |

`clean` 12.4% → `opus` 12.7%。**コーデックによる劣化はほぼ無い。**

### 混在音声 ← 決め手はここ

| 設定 | WER | 書き起こした語数の割合 | 英語部分が残った件数 |
|---|---:|---:|---:|
| gpt-4o / lang=tl | 51.7% | **0.54** | 5/20 |
| gpt-4o / lang=en | 51.0% | **0.53** | 3/20 |
| gpt-4o / lang=auto | 51.4% | **0.53** | 4/20 |
| **whisper-1 / lang=tl** | **23.2%** | **0.99** | **16/20** |
| whisper-1 / lang=en | 51.0% | 0.51 | 20/20 |
| whisper-1 / lang=auto | 30.0% | 0.97 | 16/20 |

**gpt-4o-transcribe は 20件中20件で片方の言語しか書かない。**
WER 51% の中身は誤りではなく**欠落**。しかも残った文章は自然に読めるので、
**読んでも落ちたことに気づけない。**

### ノイズ

whisper-1 50.0% / gpt-4o 44.8%。whisper は**言っていない文を作る**
（WER 150%＝参照より長い出力）。⚠️ ノイズのレベルは実測ではないので、
「壊れる」は確かだが「どのレベルで壊れるか」は言えない。

## いまの結論（暫定）

1. **whisper-1 + `language=tl`** が第一候補。単一言語では 4o が上だが、
   応募者が話すのはタグリッシュ。**速くて半分落とすより、遅くて全部書く方。**
2. `language=en` は両モデルとも致命的（もう一方の言語を落とす）。
3. **語数と録音秒数を突き合わせる見張り**をエンジンとは別に持つ。
   90秒で15語しか返らなければ、何かが落ちている。

## この検証の限界（重要）

- FLEURS は**読み上げ**。応募者は読み上げない。
- 混在音声は**話者が切り替わる**（別録音の連結）。実際のタグリッシュは
  **同じ人が文中で切り替える**。「4o が半分落とす」のが話者の切り替わりに
  よるものか言語の切り替わりによるものか、**この検証では区別できない**。
- n=20。同一設定の再実行で 7.9% と 6.6% が出た。**1〜2ポイントの差は差ではない。**

→ **実際のタグリッシュ音声で確かめるまで、順位を確定しない。**

## 再現方法

```bash
python3 -m venv venv && ./venv/bin/pip install "datasets<4" soundfile jiwer openai
export OPENAI_API_KEY=$(heroku config:get OPENAI_API_KEY -a sushizen-shift-app)
./venv/bin/python fetch2.py        # fil_ph を20文（tar.gz を途中で打ち切って取得）
./venv/bin/python fetch_en.py      # 同じ文IDの英語
./venv/bin/python degrade.py       # opus / noisy を生成
./venv/bin/python build_mix.py     # 混在音声を生成
./venv/bin/python run2.py manifest_mix.json opus whisper-1 tl
```

音声そのものは `~/Desktop/stt-eval/audio/`（約4 MB）。
FLEURS からいつでも取り直せるので、リポジトリには入れていない。
