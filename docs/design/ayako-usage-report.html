評価者として

8月7日、TAFTの評価で coaching と problem_awareness に「1」 を付け、 理由欄に “I have not visited the store.” と書いています。 訪問していない日に、正直にそう記録した唯一の人物です。

ただし同じ日に backup=4 / quality=3 を記入しています。 訪問していないのに他項目を埋めているのは矛盾で、ここは本人に確認する価値があります。 ——もっとも、これはフォームが未訪問を扱えないことの表れでもあります。 「訪問なし」を選べれば、正直な人が矛盾した記録を残さずに済みます。

9月に入ってから

9月1日〜3日で、ログインは3日間・16セッション、 OSに残った操作はシフト変更1件のみです。

データからは区別できません

これは2通りに読めます。 ①OSが記録しない仕事（画面を読む・Discord・会議・外部ポータル）に移っている、 ②単に静かな3日間だった。 3日間だけでは判断できません。Yuriのレポートと同じ限界です。

読み取れること

1 ・ 担当領域が広く、一貫して触っています。 シフト・店舗評価・NTE・小口現金・スポット購買・給与調整と、6領域にまたがっています。 23日間途切れていないので、放置している持ち場は見当たりません。

2 ・ 1件あたりの重さがある業務です。 NTE審査9件・小口現金11件・給与調整9件は、件数こそ少ないものの 1件ずつ内容を読んで判断する種類の仕事です。 件数の多寡だけでYuri（1,499件）と比べるのは適切ではありません。

3 ・ シフトの手作業は5日に固まっています。 セル編集539件が8/22・23・27・28・29の5日に集中しており、 週次の公開作業として自然な形です。

4 ・ 承認を素通ししていません。 小口現金で却下6件（承認5件より多い）。 承認権限を持つ担当者としては、これが最も重要な数字です。

この数字で言えないこと

働いた時間は測れません。 ログインセッション121回は「ブラウザを開いた回数」であって、労働時間ではありません。 Yuriのレポートで示したとおり、セッションは日をまたいで開きっぱなしになります。

質は測れません。 NTE審査9件が適切だったか、店舗評価6件が現場を反映していたかは、この集計では分かりません。 店舗評価については別途の調査で「評価者全体として客観データと連動していない」と出ています。 これは本人個人の問題ではなく、フォーム設計の問題です。
